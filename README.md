# TP08_CBTDSIM

Desenvolva um programa em COBOL capaz de manipular o arquivo ALUNOS.DAT, do 6º TP.

O programa deverá apresentar um menu com as 
seguintes opções:

a) Incluir Registro
b) Excluir Registro
c) Listar Registros
d) Sair

As buscas ao registro, para exclusão, deverá ser feita pela matrícula.

Sempre, ao sair ou listar, gravar o arquivo ordenado (de forma crescente) pelo nome do aluno.
Ao terminar, caso se use arquivos secundários, apagar os mesmos, restando apenas o arquivo ALUNOS.DAT
atualizado.
